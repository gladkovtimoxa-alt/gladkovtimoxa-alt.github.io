Полное руководство по распознаванию текста с фото

08.11.2026 · автор: Тимофей Гладков

Кратко: это руководство собирает все способы распознать текст с фото в KaTiAi в одном месте — для работы с документами, для учёбы и для личных бумаг. Если нужен только самый частый случай, начните с базовых статей: как распознать рукописный текст с фото и как распознать таблицу с фото и перенести в Excel.

Сфотографировать лист — легко. Дальше нужно текст найти, проверить, перенести в файл или в таблицу — и тут разные задачи решаются по-разному. Печатный текст читается бесплатно прямо в браузере. Рукопись, таблицы и перевод — в ИИ-режиме. Поиск по большому архиву — через PDF с поиском. Ниже — статьи блога KaTiAi, сгруппированные по тому, зачем вам нужно распознавание.

Для работы

  • Как распознать таблицу с фото и перенести в Excel — строки и столбцы в CSV без ручной расстановки
  • Чеки за месяц — это 30 фото в галерее — один файл с поиском по сумме и магазину
  • ИИ ускоряет сверку, но подпись ставите вы — что в акте сверки стоит проверить глазами
  • PDF, в котором ищется любое слово — из пачки фото в один документ с поиском
  • Перепечатанная цитата — риск опечатки в жалобе — точная цитата с номером листа без перенабора
  • Архив заявлений можно искать по фамилии — годовой архив за три шага
  • Нужный протокол ищется листанием — том дела с поиском по фамилии
  • «Пришлите копию акта» — и вы её не находите — как не искать документ по полгода
  • Ведомость руками — и страх, что в цифрах ошибётесь — рукописная ведомость в Excel без перебивания
  • Размытое фото от клиента? — что делать, если переснять нельзя
  • Старый договор аренды — и нужное слово находится — поиск по старому принту без перепечатки
  • Распознать и перевести — одно действие, а не два сервиса — перевод документа в одном окне
  • Паспортные данные в бесплатном онлайн-конвертере — риск для компании — почему распознавание на своём устройстве безопаснее
  • 10 страниц договора — один файл, а не 10 сообщений — альбом фото в один документ по порядку
  • Резюме: 30 листов — один файл — поиск кандидата по имени вместо папки листов
  • KaTyAi против перепечатки: сколько вы реально тратите — честный подсчёт часов на ручной набор
  • KaTyAi против бесплатного онлайн-OCR: в чём разница — лимиты, формат и куда уходит фото
  • Акт сверки в скане сверяется построчно — или в Excel формулой за минуты
  • Правки в скане чужой редакции видно только при чтении вслух — сравнение редакций договора в Word
  • Выписка банка: сфоткай, не перепечатывай — таблица из выписки прямо в Excel
  • Не перебивай счёт-фактуру — хватит одного фото — суммы и ИНН без перенабора
  • Новый сотрудник: 8 документов — без перебивания — личное дело за один заход
  • Описание квартиры: из блокнота — в объявление, без перебивания — рукописные заметки риелтора в текст
  • Ведомость клиента от руки — в файл без перебивания — расходы клиента без перепечатки
  • Табель учёта: без перебивания часов — часы с фото табеля в файл
  • Сфотографируйте сотни страниц дела за одну минуту — скан, перевод и таблицы одним ботом

Для учёбы

  • Сфотографировали домашку — а половина букв потерялась — как снять задание, чтобы буквы не пропадали
  • Контрольная на два варианта из сборника — без набора — задание в DOCX вместо перепечатки
  • Источник на английском — не повод переводить вручную — распознать и перевести страницу источника
  • 40 источников в списке — и переписывать их не нужно — список литературы в дипломе за 5 минут
  • Сложная вёрстка — колонки и сноски — ломает обычный OCR — что сохраняет Pro-режим в журнальной странице
  • Перечитывать тетрадь перед экзаменом — долго — билеты по темам вместо тетради целиком
  • Сессия через неделю, а конспект в трёх тетрадях — три вечера на конспект с поиском
  • Оценки с бумажной ведомости не нужно перебивать — ведомость в CSV для таблиц
  • Комментировать рукописную работу на полях — тесно — разбор работы ученика в примечаниях Word
  • Задания из бумажного сборника не нужно переносить в Word — карточки для класса из готового сборника

Для личных документов

  • Почерк прадеда — тот, что не читаешь уже 20 лет — старые письма для всей семьи
  • Документы с айфона: без приложений-сканеров — файл прямо из мессенджера
  • Пачка фото объявления в чате родителей — неудобно — один PDF вместо пачки фото
  • Выписка: с бумаги — в файл — больничная выписка, которую удобно хранить и пересылать
  • Акт приёма-передачи: сфоткай, не перепечатывай адрес — акт при сдаче или приёмке квартиры
  • Тетрадь с рецептами выцветает — семейные рецепты, пока почерк ещё читается
  • Почерк врача — в читаемый текст — дозировки и даты без догадок

Как выбрать режим

  • Бесплатный режим — печатный текст, без регистрации, прямо в браузере; фото не уходит на сервер.
  • ИИ-режим (Pro) — рукопись, таблицы, перевод, PDF с поиском; 2 ₽ за страницу.
